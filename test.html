User acceptance test plan WebBusters

 

Specify the tests:

 

Test

Test type

Test Description

1

Functional

The user successfully selected the correct treasure hunt and entered a username that has not been previously used and successfully started playing the game.

 

2

Usability

Users can intuitively navigate through the questions without the help from the team. They can understand the question and how to answer them depending on their type (numeric, multiple choice or true or false) without having to ask the team what they should do next. They are aware that a help button is displayed on the top of the page to help them throughout the game.

 

3

Design

 

The user is not overwhelmed by the colors of the design or multiple images that could be distracting while answering the game. Background image and colors are pleasing to the eye of the player.

 

4

Error-prevention

 When a user makes a mistake, for example using a username that already exists, an error message is displayed to show them how to fix it, so they can move on to answering the questions.

 

The area of the buttons that a user will press to answer the questions are large enough so they can press the correct button without accidentally pressing a wrong button ( e,g, skip button).
